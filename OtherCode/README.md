# OtherCode Projects

This folder contains separate language project examples for the portfolio site.

## Add a new project

1. Create a new folder under `OtherCode` for the language or framework.
2. Add a short README or project file with the project name and a link.
3. Update `Typescript/mainTS.ts` project data in the `projectGroups` array.

## Language folders

- `C-Cpp` - native C and C++ sample code.
- `Python` - simple Python utility or script.
- `CSharp` - C# console or Unity-compatible sample.
- `Go` - small Go command-line project.
